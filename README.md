# 敬友館 なんたん大会ボード

第11回なんたん空手道交流大会（2026年10月4日・亀岡運動公園体育館）の当日用。
敬友館の選手の出番・予選の順位・決勝トーナメント・団体戦を、監督と保護者の全員で入力・共有する。

- 画面: `index.html`（GitHub Pages でそのまま配信）
- データ: Firebase Firestore（前回の監督ナビと同じプロジェクト。この大会の文書は `n11-` で始まる）
- 名簿（選手名）は Firestore 側にあり、このリポジトリには置いていない
- 入力の取り消し: 保存直後の「取り消す」／「進行・履歴」タブの「元に戻す」
- 動作確認: URL の末尾に `?test` を付けると本番と別のデータで試せる
